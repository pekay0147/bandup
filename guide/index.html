휴대폰 홈 화면에
밴드업 앱 추가하기

한 번만 해 두면 앱처럼 아이콘을 눌러 바로 공부할 수 있어요. 1분이면 끝나요.

  1. 사파리로 열기

    선생님이 보내드린 내 앱 링크를 사파리(Safari)로 열어 주세요.
    카카오톡에서 링크를 눌렀다면 오른쪽 아래 ⋯ 또는 공유를 누르고 Safari로 열기를 고르세요.

  2. 공유 버튼 누르기

    화면 아래(또는 위) 가운데에 있는 공유 버튼을 눌러 주세요. 네모에서 위로 화살표가 나온 모양이에요.

  3. ‘홈 화면에 추가’ 고르기

    목록을 아래로 조금 내리면 홈 화면에 추가가 있어요. 안 보이면 맨 아래 작업 편집에서 찾을 수 있어요.

  4. ‘추가’ 누르기

    오른쪽 위 추가를 누르면 끝! 홈 화면에 밴드업 아이콘이 생겨요.

  1. 크롬으로 열기

    선생님이 보내드린 내 앱 링크를 크롬(Chrome)으로 열어 주세요.
    카카오톡에서 링크를 눌렀다면 오른쪽 위 ⋮를 누르고 다른 브라우저로 열기를 고르세요.

  2. 메뉴 누르기

    크롬 오른쪽 위의 ⋮ (점 세 개) 버튼을 눌러 주세요.

  3. ‘홈 화면에 추가’ 고르기

    메뉴에서 홈 화면에 추가를 눌러 주세요. 휴대폰에 따라 앱 설치라고 나올 수도 있어요.

  4. ‘추가’ 또는 ‘설치’ 누르기

    추가(또는 설치)를 누르면 끝! 홈 화면에 밴드업 아이콘이 생겨요.

삼성 인터넷을 쓰신다면아래쪽 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면을 누르면 돼요.

이 아이콘이 생기면 성공이에요.
앞으로는 이 아이콘으로 들어와서 공부해 주세요.

알아 두세요
  • 공부 기록은 내 휴대폰에 저장돼요. 휴대폰을 바꾸거나 앱을 지우면 기록이 처음부터 시작돼요.
  • 아이폰은 사파리와 홈 화면 앱의 기록이 따로 저장돼요. 처음부터 홈 화면 아이콘으로 공부하는 게 좋아요.
  • 잘 안 되면 선생님께 화면을 캡처해서 보내 주세요.
